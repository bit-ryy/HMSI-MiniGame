# HMSI Mini-Games // SI Edition

Koleksi web mini-game interaktif berbasis Vanilla JavaScript (ES6 Modules), HTML5, dan CSS3

## Daftar Game

1. **Data Wave Runner** (`./data-wave-runner/`)
   - *Genre:* Arcade Wave Runner (HTML5 Canvas)
   - *Fitur:* Sistem 3 Tema (Gelap/Terang/Sistem), Web Audio API Synthesizer, kontrol responsif Desktop & Mobile (Portrait/Landscape).
2. **Whack-a-Bug** (`./whack-a-bug/`)
   - *Genre:* Reflex Grid Whacking (DOM 3x3)
   - *Fitur:* 4 tingkat kesulitan, dukungan kontrol Numpad/Mouse/Touch, Haptic Feedback (getar sentuh mobile), dan persistent High Score.
